# Reference

Reference material, for looking things up: the syntax of models and properties, the command-line switches, the file formats that PRISM uses for models that have already been constructed, and the papers cited in this manual.

## Contents

- [PRISM language syntax](PRISMLanguageSyntax.md): model and property files, model types, identifiers and keywords, expressions, and legacy syntax
- [Command-line switches](CommandLineSwitches.md): all the switches of the command-line version of PRISM, as listed by `prism -help`
- [Explicit model files](ExplicitModelFiles.md): the formats of files for states, transitions, labels and rewards
- [References](References.md): papers cited in this manual
