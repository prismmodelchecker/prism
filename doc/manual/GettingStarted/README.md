# Getting started

How to install PRISM, solve common problems with installing and running it, and start using it.

If you are new to PRISM, [install it](Installing.md), then see "[First steps](FirstSteps.md)" for how to start the GUI and the command-line version.
The [tutorial](https://www.prismmodelchecker.org/tutorial/) on the PRISM website is a good next step.

## Contents

- [Installing PRISM](Installing.md): installing a binary release, or compiling from source, on Windows, macOS and Linux
- [Troubleshooting](Troubleshooting.md): problems installing, compiling or running PRISM, and their solutions
- [First steps](FirstSteps.md): starting the GUI and the command-line version of PRISM
